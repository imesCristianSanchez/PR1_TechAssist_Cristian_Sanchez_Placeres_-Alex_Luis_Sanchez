# PR1_TechAssist
Práctica 1 — Diseño de Bases de Datos y Modelo Entidad-Relación
Integrantes:
Cristian Sánchez Placeres  
Alex Luis sanchez

Objetivo del proyecto

El objetivo de esta práctica es diseñar una base de datos para TechAssist, una empresa de soporte y asistencia informática. Hay que organizarla información de clientes, técnicos, departamentos, incidencias y servicios, evitando duplicación y con relaciones coherentes

Descripción del modelo

El diseño se basa en un modelo Entidad-Relación que representa las entidades principales, sus atributos, las relaciones y sus cardinalidades. Posteriormente, el modelo se transforma en tablas con claves primarias (PK) y claves foráneas (FK).

El sistema contempla las intervenciones de los técnicos en las incidencias, los departamentos a los que pertenecen los técnicos y la especialización de los servicios en presenciales y online.
